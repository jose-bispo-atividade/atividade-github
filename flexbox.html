Bem-vindo ao meu site de exemplo Flexbox

Este site utiliza um arquivo CSS separado, para criar o menu horizontal com Flexbox, alem de uma aparencia limpa e moderna

as tags exigidas estao todas presentes: <hearder>,<main>, <div>, (Container interno)<h1> entre outros.

O menu horizontal e obtido com display: flex na lista ,<ul>. O CSS externo facilita a manutencao e o aprendizado separado da estrutura e da apresentacao.

Agora o HTML cuida do conteudo e o CSS do visual. Basta salvar dois arquivos e direcionar o link para o arquivo correto.
